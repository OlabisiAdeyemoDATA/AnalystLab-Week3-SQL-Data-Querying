# AnalystLab Africa - Week 3: SQL & Data Querying

## Project Overview

This project focuses on applying SQL skills to solve real-world business problems using two datasets:

1. Chinook Database (Music Store Data)
2. Sales Dataset (AdventureWorks Lite Equivalent)

The objective was to extract, transform, and analyze structured data using SQL to generate actionable business insights.

## Business Questions Solved

### Chinook Database

* Top customers by spending
* Revenue by country
* Top selling music genres
* Employee performance
* Monthly revenue trends
* Customer purchasing behavior

### Sales Dataset

* Total revenue analysis
* Revenue by year
* Revenue by product line
* Top customers
* Revenue by country
* Deal size analysis
* Customer purchasing behavior

---

## Key Insights

* High-value customers contribute significantly to revenue.
* Revenue distribution varies across countries.
* Product performance differs across categories.
* Large deals contribute substantially to total sales.
* Customer behavior patterns can inform retention strategies.
